# 鲸鱼娘桌宠（whale-pet）

运行在 Windows 10/11 上的 AI 桌面宠物，非官方同人项目，与 DeepSeek 官方无关，仅供个人使用。

详细需求见 [SPEC.md](SPEC.md)。

## 素材与授权

角色立绘素材来自 [Sutera-Diffusus/dsh-whale-musume](https://github.com/Sutera-Diffusus/dsh-whale-musume)（MIT License，版权方 Sutera-Diffusus），以 git submodule 形式引入到 `assets/whale/`，原始 `LICENSE` 文件随 submodule 一并保留。

本仓库自身的代码同样以引用该素材仓库的方式使用，不修改、不重新分发素材文件本身。

## 开发环境

- Node.js（LTS）、npm
- Windows 10/11（部分功能，如窗口标题读取、全局按键监听，依赖 Windows API）

## 首次拉取代码


## 安装依赖 / 运行

```bash
npm install
npm start
```

`npm start` 会先用 `tsc` 编译 TypeScript、把渲染进程用到的静态文件复制到 `dist/`，再启动 Electron。

其他命令：

```bash
npm run typecheck   # 只做类型检查，不产出文件
npm test            # 先 build，再跑 tests/ 里的纯函数单元测试（node --test）
```

### 起不来的时候

`npm start` 走的是 `node scripts/start.js`，它会帮你去掉环境里的 `ELECTRON_RUN_AS_NODE`。

这个变量很坑：它由某些终端/工具链（比如 DSH 的终端）默认设置，一旦存在，`electron.exe` 会以**纯 Node 模式**启动——`require('electron').app` 是 `undefined`，主进程第一行就崩，表现就是"npm start 完全跑不起来，也不说为什么"。手动跑的话：

```powershell
Remove-Item Env:ELECTRON_RUN_AS_NODE   # PowerShell
# set ELECTRON_RUN_AS_NODE=           # cmd
```

## 打包成安装包（不用终端就能启动）

```bash
node scripts/build-installer.js      # 等价于 npm run dist:win
```

产物在项目目录**旁边**的 `../whale-pet-release/`：

| 文件 | 用途 |
|---|---|
| `鲸鱼娘桌宠 Setup 0.1.0-alpha.1.exe` | 双击安装（向导式，可选安装目录），会创建**桌面 + 开始菜单快捷方式**——以后点图标就能启动，不用终端 |
| `win-unpacked/鲸鱼娘桌宠.exe` | 不想安装就直接跑这个（免安装版） |

装完/跑起来之后，数据仍在 `%APPDATA%\whale-pet`（和开发版**同一份**），所以 API Key、设置、聊天记录、长期记忆都不会丢。

### 怎么退出

**右键托盘图标 → 退出**。（托盘是独立窗口，托盘菜单永远能用——即使桌宠本体被别的东西挡住、或者点了没反应。）

托盘图标也被挡住了的话：

```powershell
taskkill /IM 鲸鱼娘桌宠.exe /F        # 开发版是 taskkill /IM electron.exe /F
```

任务管理器里结束 `鲸鱼娘桌宠`（开发版是 `electron`）进程也一样。

### 出问题看日志

打包版是 GUI 进程，**没有终端**，所以关键信息都会写进文件：

```
%APPDATA%\whale-pet\logs\app.log
```

里面有：启动信息（版本 / 是否打包版 / 数据目录 / 素材目录 / **API Key 状态**）、主进程未捕获异常、**渲染进程的报错**（preload 里挂了钩子）、聊天请求失败的原因。文件不会无限长大（超过 200KB 只留最后 100KB）。

**两个坑（脚本已经处理，记在这里免得以后重新踩）：**

- **素材路径要分开发/打包两种环境**：打包后代码在 `app.asar` 里，而素材和人设是通过 `extraResources` 放在 asar **外面**的 `resources/whale-assets`、`resources/persona`（见 `src/main/paths.ts`）。素材连同它自己的 `LICENSE` 一起分发，满足授权要求。
- **目录重命名 + 解压这两步容易失败**：electron-builder 解压 Electron 后要把 `win-unpacked.tmp` 改名成 `win-unpacked`，目标已存在时会 EPERM（脚本每次先清理）；另外当前工作区里"重命名目录"被一条 Windows 权限拒绝（DSH 沙箱留在工作区根目录上的 Everyone 拒绝项，非受限进程也会被拒），所以产物目录放在工作区外，并用本地已解压的 Electron（`electronDist`）跳过下载解压。
- 应用名用 `app.setName('whale-pet')` 钉死了：安装包的产品名是中文（快捷方式显示"鲸鱼娘桌宠"），如果让它参与算数据目录，打包版就会去读一个空目录、你的 Key 会"消失"。

## 首次使用：填 API Key

阶段 2 起需要接 DeepSeek（或其他 OpenAI 兼容服务）才能聊天。托盘图标右键 → 设置，或者在桌宠身上右键 → 设置，填 API Key、Base URL（默认 `https://api.deepseek.com`）、模型名（默认 `deepseek-chat`）。Key 用 Electron `safeStorage` 加密存在本机，不会进代码库或日志。

人设文件在设置里点"打开人设文件"就能编辑，改完直接保存生效，不用重启、不用点"重新加载"。首次启动会自动把 `persona/default.md` 复制一份到用户数据目录，以后改的是那份复制出来的，不会因为代码更新被覆盖。

### Key 明明填过却说没有？

设置页顶部会显示 Key 的**三种状态**，写得很直白：

- `还没设置，回复消息前必须先填一个` —— 真的没填过。
- `已设置（留空保存 = 不修改）` —— 正常，能用。
- `本机存着的 Key 读不出来了（原因…）` —— **文件在，但解不开**，红字提示，重新填一次就好。

Windows 上 Key 是用 Chromium 的 safeStorage（OSCrypt）加密的：文件里的密文要靠同一个应用数据目录下 `Local State` 里的密钥才能解开，而那个密钥又由 Windows 账户的 DPAPI 保护。所以**重启电脑本身不会让 Key 失效**，但下面这些会：换了 Windows 账户、重置过系统密码、或者换了应用数据目录（比如直接用 `electron 某个js文件` 启动，应用名会变成默认的 `Electron`，目录也跟着变，等于换了个 profile）。

排查命令（会打印目录、加密是否可用、能不能解开，不会打印 Key 内容）：

```powershell
Remove-Item Env:ELECTRON_RUN_AS_NODE -ErrorAction SilentlyContinue
node_modules\electron\dist\electron.exe scripts\diagnose-key.js
```

## 聊天怎么用

两个入口，共用同一份聊天记录和同一个人设：

- **聊天面板**：在桌宠身上右键 → 聊天（或点气泡正文）打开，可以往上翻历史、Enter 发送、Shift+Enter 换行。顶部有个「新对话」按钮。
- **气泡快捷回复**：不用开面板，直接在气泡下面那行输入框回一句。
- **查余额**：在桌宠身上右键 → 「💰 查余额」，她会现查一次、用气泡把数字报出来；也可以直接在聊天里问（"我还有多少余额呀"）。数字是程序**实时查出来的真数据**（快照超过 1 分钟就重查一次），再交给她用自己的语气说——所以她不会瞎编数字；服务不支持查余额或查询失败时，她也会照实说。

### 上下文（对话）是怎么算的

像常见 LLM 那样按"对话"分段，但**人设和长期记忆永远都在**——所以她始终记得你，只是不会把不同场景搅在一起：

- **她说主动说话（久坐/喝水/深夜/窗口吐槽/哲学问题/余额提醒）不进聊天记录**。那些话只是冒个气泡，不会混进你和她的对话里。
- **在气泡里回复她的主动说话 = 开启一段新对话**：那句话会作为新对话的开头记下来，之后你们就在这段新对话里聊；之前那段对话留在记录里给上面翻看，但不进模型上下文。
- 面板里的「新对话」按钮同理：手动开一段干净上下文。
- 面板里会用一条 `新的对话` 分隔线把各段标出来。

### 其他行为约定

- **一次只跑一轮**：她还在回上一句时再发会被挡下来（面板的输入框本来就锁住了，气泡的输入框也会锁）。
- **可以中途停止**：发送中面板上会多出一个「停止」按钮。已经吐出来的部分会留在记录里当这一轮的回复；一个字都没收到的话，那条提问会从记录里撤回，界面上会给它标一个「已停止，这句没记下」。
- **发送失败**：错误信息以红字显示在面板里，同时那条提问从记录里撤回（避免留下"提问没有回答"的断层），界面上会标「没发出去，记录里也撤回了」。
- **面板开着的时候不弹气泡**：文本已经在面板里了，弹出来只会挡视线——这时只换表情。面板关掉后，最后一句会用气泡补上（SPEC §5.2 的要求）。回复打到一半关掉面板也不会丢：这句话照样进记录，并改用气泡显示。
- **面板不跟着她移动**：只在打开的那一瞬间摆在她旁边（她贴屏幕右边时会翻到左边），之后她走动或被拖走，面板都待在原地——跟着跑、还在左右之间来回翻，反而看不清在聊什么。
- 崩溃或强退留下的"没人回答的提问"，下次启动时会自动清理掉。

## 气泡

- 默认显示 **8 秒**；你回过话之后它就**一直留着**，只能点气泡右上角内侧的小 **×** 关掉（正在等她回复时也不会自动消失）。
- **高度跟着文字实时长**：装得下就完整显示，最多长到 300px，再长就在气泡内部滚动——不会出现"下面的字被切掉""上面被切掉"或者输入框被挤出屏幕。
- **她走动时气泡只挪位置、不改尺寸**：尺寸只由内容决定，移动过程不会变高变矮。
- 气泡下面可以直接回她一句；等回复期间输入框是锁着的，避免连发互相覆盖。
- 点气泡正文 = 打开完整聊天面板。
- 如果这条气泡是**她主动说的话**，你在下面回复会开启一段新对话（见上面「上下文是怎么算的」）。
- 右键菜单**开着的时候会跟着她挪**（不然她走开了，菜单就孤零零留在原地指着空气）。
- 气泡和右键菜单都会按**角色实际画面**（不是那个 220×220 的方形窗口，周围一圈是透明的）来避让屏幕边缘：人物贴着左边时气泡/菜单出现在右边，贴着右边时翻到左边，上下也会夹进工作区。摆位算法在 `src/main/popupPlacement.ts`，有单元测试。

## 当前进度

- **第一版 alpha 已经打包**（`0.1.0-alpha.1`）：装完就有桌面/开始菜单快捷方式，不用再开终端跑 `npm start`。见上面「打包成安装包」。
- 阶段 0：项目骨架（透明置顶空窗口）
- 阶段 1：桌宠本体（显示、待机动画、拖拽抛出、摸头摸尾巴、随机走动、扒边缘探头、全局快捷键、托盘菜单、桌宠右键菜单）
- 阶段 2：聊天与人设（DeepSeek/OpenAI 兼容 provider、聊天面板、人设文件、设置界面）
- 阶段 3：主动说话（久坐/喝水/深夜提醒、窗口标题吐槽 + 隐私过滤、随机哲学问题、勿扰开关、触发频率可调）
  - 你离开电脑超过设定时间（默认 3 分钟，设置里可改）她会换成趴着的姿势（`afk`），深夜则换成坐着睡的姿势（`sleep`）；动一下键盘鼠标她就醒过来打个招呼。
  - 深夜提醒会切 `night` 姿势；余额不足会切 `balance-low` 姿势 + 冒气泡（只在从"够用"变"不足"时提醒一次）。
- 余额显示：设置页「账户余额」和托盘菜单都能看到数字，也能手动刷新。查的是 DeepSeek 官方 `/user/balance` 接口，启动查一次 + 之后每 6 小时一次；换成别的 OpenAI 兼容服务会显示"该服务没有余额查询接口"。低于设定阈值（默认 5）时她会提醒一下。
- 阶段 4：记忆（聊天记录持久化 + 长期记忆）
  - 聊天记录存在本机，重启后打开聊天面板能接着聊；发给模型时只带最近 N 轮（设置里可改，默认 20），设置页能看条数、也能一键清空。
  - 长期记忆：每聊够 N 轮（默认 5）让模型从对话里提取"值得长期记住的事实"，下次聊天时注入 system prompt；设置页可以看列表、逐条删除、清空全部，也能直接打开 `facts.json` 手写。
  - 隐私：提取时的提示词里明确禁止记录密码/API Key/身份证号/银行卡号/手机号/住址，落盘前还会再过一遍正则过滤。
- 打磨（都是实际用出来的问题）：
  - 修掉"透明窗口一移动就改尺寸"的系统坑：她走动时窗口不再越走越大，点击判定和气泡/右键菜单的摆位也跟着准了。
  - **主动说话不再写进聊天记录**；在气泡里回复她 = 开启一段新对话（人设和长期记忆照旧，所以她还是记得你）。
  - 聊天面板加了「新对话」按钮和对话之间的分隔线。
  - 窗口标题的中文修好了（之前 PowerShell 用的是 ANSI 版 API，中文标题全变成 `??`，模型只能对着乱码吐槽）。
  - 同一句主动说话不会连着说两遍；主进程的未捕获异常改成写日志，不再弹 "A JavaScript error" 对话框。
  - 她**扒在屏幕边缘/底边（探头）时说话会保持那个姿势**，不换表情也不站起来乱走（你把她拖到角落就是为了让她别打扰你）；摸头/投喂这类互动演完表情后也会回到探头姿势。
  - 气泡的小 × 移到气泡内侧，右上角不再被窗口边缘切掉；气泡高度跟着文字实时长，流式回复时顶部也不会被裁。
  - 聊天里可以直接问余额，右键菜单里也有「💰 查余额」（她现查一次、用气泡报出来）：数字是程序查的真数据，她不会瞎编。
  - 余额的显示统一了：托盘菜单、设置页、气泡、聊天里用的是同一个格式化函数，同一个数；设置页还会在主进程查到新余额时**自动刷新**（以前它一直显示打开那一刻的旧数字）。
  - 修掉一个会让余额显示成 0 的 bug：DeepSeek 会同时返回人民币和美元两条余额，**顺序还不固定**，之前取第一条，碰上美元那条（0.00）在前就显示 0、还会误报"余额不足"。现在会挑出真正在用的那条（非零优先，其次人民币）。

## 本机数据都存在哪
Windows 下都在 `%APPDATA%\whale-pet\`（Electron 的 userData 目录），不会进代码库：

| 文件 | 内容 |
|---|---|
| `settings.json` | 设置项（不含 API Key） |
| `apikey.enc` | API Key（`safeStorage` 加密） |
| `personas/default.md` | 你正在用的人设文件 |
| `chat/history.json` | 聊天记录（最多 400 条） |
| `memory/facts.json` | 长期记忆 |

## 项目结构

```
whale-pet/
├─ assets/whale/         # 素材 submodule（含原始 LICENSE）
├─ src/
│  ├─ main/              # Electron 主进程：窗口、托盘、快捷键、IPC、本地配置、
│  │                      #   聊天会话、人设、API Key 加密存储、
│  │                      #   空闲检测（presence.ts）、余额查询（balance.ts）
│  ├─ renderer/           # 桌宠渲染、动画状态机、点击穿透、拖拽物理、
│  │                      #   右键菜单/聊天面板/设置界面/气泡的页面内容
│  ├─ core/providers/     # ChatProvider 接口 + OpenAI 兼容实现（预留 Anthropic）
│  └─ shared/             # 主进程和渲染进程共用的类型定义
├─ scripts/              # 构建辅助脚本
├─ persona/              # 默认人设文件（首次启动会复制到用户数据目录）
└─ SPEC.md               # 完整需求说明
```
